Giới thiệu website

Website được xây dựng nhằm giới thiệu kiến thức cơ bản về thiết kế web và lập trình. Bố cục gồm phần đầu trang, thanh điều hướng, nội dung chính và chân trang.

Nội dung học tập

HTML

• Xây dựng cấu trúc trang web bằng các thẻ HTML.

CSS

• Thiết kế giao diện, màu sắc và bố cục trang web.

JavaScript

• Tạo các chức năng tương tác cho website.
